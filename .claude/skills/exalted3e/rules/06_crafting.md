# Crafting — Live Adjudication

Crafting roll: **(Attribute + appropriate Craft)** vs. a difficulty. The structure around it is **project tiers**, **project slots**, and **craft XP**. *(Core Rulebook › Crafting)*

---

## Project Tiers *(Core Rulebook › Crafting)*

- **Basic** — chair, tools, a meal, an arrow. Trivial time/materials.
- **Major** — battle-ready arms/armor, a banquet, a statue. Significant time/materials.
- **Superior** — (1) **artifacts** (magical gear), and (2) **large-scale construction** (warship, palace) — the latter is the only superior project mortals can attempt.
- **Legendary** — N/A-rated wonders, lost First Age glories.

---

## Craft XP *(Core Rulebook › Crafting Experience)*

Three flavors, each spent **only on crafting** (never on Attributes/Charms/etc.):
- **Silver (sxp)** — from basic projects → spent on **major** projects.
- **Gold (gxp)** — from major projects → spent on **superior** projects.
- **White (wxp)** — from superior projects → spent on **legendary** projects.

### Basic Objectives (reward triggers) — stack, up to 3 per project
Earn a reward for **each** that the finished project triggers:
1. It makes another character gain/strengthen an Intimacy **toward you**.
2. It produces a clear in-game gain (payment, new Merit like Allies/Contacts).
3. It upholds/furthers/protects one of **your** Intimacies.

### End-of-story craft XP
- **+3 sxp** per Craft rated **3+** used to finish a project this story.
- **+5 sxp** per Craft rated **5+** used to finish a project this story.
- **+5 gxp** per **artifact** successfully created this story.

---

## Project Slots *(Core Rulebook › Elements of Crafting; Project Slots)*

Abstract focus limit. Default = **3 major slots**.
- **Major** project → 1 major slot. (Need more? buy an extra for **5 sxp**, vanishes at project's end.)
- **Superior** project → fuse **(artifact rating)** major slots **+ pay (rating) gxp**.
- **Legendary** project → **5 wxp** to create a legendary slot (no fusing).

A slot is occupied until the project ends in success *or* failure.

---

## Resolving Each Tier

### Basic *(Core Rulebook › Basic Projects)*
- Needs tools/materials/Craft. **No slot, no XP cost.**
- Work minutes–hours, then roll **(Attribute + Craft)** vs. ST difficulty.
- **Reward:** **2 sxp** per objective (**3 sxp** if successes ≥ difficulty + 3).

### Major *(Core Rulebook › Major Projects)*
- Uses a major slot. Work hours–days (sometimes weeks).
- Finishing **costs 10 sxp** to make the **(Attribute + Craft)** roll. Failure → spend another 10 sxp to retry after a bit more work.
- **Reward:** **2 gxp + 1 sxp** per objective (**3 gxp + 1 sxp** each if successes ≥ diff + 3).

### Superior (Artifacts) *(Core Rulebook › Superior Projects)*
- **Requirements:** Essence-user, **Lore 3, Occult 3**, relevant mundane Craft **4+**, dots in **Craft (Artifacts)**; high-quality tools + magical materials + exotic reagents.
- **Minimum labor before you may finish:** Artifact •• = 6 weeks, ••• = 3 months, •••• = 1 year, ••••• = 2 years (idle time pushes the minimum back).
- **Finishing = extended roll.** Pay **10 gxp per roll**, roll **(Attribute + lower of Craft(Artifact) or best relevant mundane Craft)**, **difficulty 5**, **terminus 6**. Goal number by rating: **•• = 30, ••• = 50, •••• = 75, ••••• = 100**.
  - **Botch** → project ruined instantly. **Hit terminus without reaching goal** → project fails; a one-of-a-kind item (all daiklaves) can **never** be remade.
- **Reward (≥1 objective):** white XP by rating — **•• = 3, ••• = 5, •••• = 7, ••••• = 9 wxp**; plus **(rating × 2) gxp per unused interval**. (No multi-objective stacking at this tier.)

### Legendary *(Core Rulebook › Legendary Projects)*
- Adds: **Lore 5, Occult 5, Craft (Artifacts) 5**, relevant mundane Craft 5, vast materials. Slot = 5 wxp.
- Labor ≥ **10 years**; finishing **costs 10 wxp per roll**; extended roll **goal 200**.
- **Reward (≥1 objective):** **10 wxp**, plus roll a full free Craft Excellency — each success = 1 gxp, each non-success die = 1 sxp.

---

## Repairs *(Core Rulebook › Repairs)*

Repair mirrors creation by tier (fix a tool = basic; reforge a sword = major; mend an artifact = superior/legendary). ST may **lower the goal number and minimum time** by damage severity. **Artifact repairs have no terminus.** A ship hull point = one major project.

**Repair rewards** (smaller): basic **1 sxp**/obj; major **1 gxp**/obj; superior artifact **(rating − 1) wxp**; legendary/N-A artifact = no XP (the restored wonder is its own reward).

---

## Artifacts, Manses & First Age (high level)

- **Large-scale construction** (ships/palaces) — superior project needing only proper Craft + materials (+ funds/manpower). Superior slot = **2 major slots + 2 gxp**; finishes like an Artifact 2 (goal 30) but ST sets the time and there's **no terminus**. *(Core Rulebook › Large-Scale Projects and Manses)*
- **Manses** — as artifacts but with **Craft (Geomancy)** (derives only from Architecture). 3-dot manse ≥ 1 yr / goal 50; 5-dot ≥ 2 yr / goal 100. N/A manse = legendary rules with Geomancy.
- **First Age Artifice** *(Core Rulebook › Craft and First Age Wonders)* — needs **Craft (First Age Artifice)** (gated behind Lore 5/Occult 5/Craft(Artifacts) 5 + Terrestrial Circle Sorcery); **all** work uses **white XP** regardless of rating; each finish/repair roll is normally preceded by a **sorcerous working** to design components (Terrestrial for rating 2–3; +Celestial for 4–5; +Solar for N/A).

---

## Quick loop
1. Classify the tier; confirm requirements & slots.
2. Pay the finishing XP (major+) and roll (extended for superior/legendary).
3. On success, tally **basic objectives** → award the matching craft XP.
4. Note: idle time pushes back artifact minimums; botch ruins a superior/legendary project.
