# Faction board
Maintained by `scripts/ex_faction.py` (state in `campaign_state.json`); starting factions in `setting/04_factions.md`.
Each faction: `Magnitude 1–5 (die d6→d20) · Cohesion · Trouble (Σ Problems; ≥ die-max → collapse) · Features · Problems(=hooks) · Interest · Reach · Goal`.
Run `ex_faction.py turn` each season; `strike A B` for a contest; the PC edits the board by adventuring (kill a Feature, solve a Problem).
