# Self-audit — silent gate before sending any scene
- Did dice decide every uncertain outcome, rolled through a script and shown?
- Did I pre-commit the stakes before rolling?
- Did NPCs/foes use their motes, Charms, and tactics to **win** (not play dumb)?
- Did I keep GM-only card **Truth** hidden (no leaking un-earned knowledge)?
- Did state update (motes, WP, Initiative, Health, Intimacies, anima, Limit; faction board; Threads)?
- **Adversity gate:** does this scene move something real — Initiative/Health lost, motes/WP burned, an Intimacy/Limit pressured, a faction Problem advanced, Reach spent, or a credible present threat? If none, it is soft — add an edge before sending.
