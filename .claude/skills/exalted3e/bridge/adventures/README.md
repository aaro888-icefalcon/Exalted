# Ingested Adventures (hook: adventure-ingest) — none yet

This companion ships **no pre-ingested module**; the `adventure-ingest` hook defers to the engine.
Solo Exalted runs as a **pure sandbox** off the generators + Creation oracle (a faction `Problem:`
is the cheapest hook of all — `generators/adventures.md`).

To ingest a published Exalted adventure later, follow `mythic-gm/references/ingest-adventure.md`
and the cluster/fragment schema in `mythic-gm/assets/bridge-templates/adventures/CLUSTER-SCHEMA.md`,
drop the resulting `*.md` here, and add `"adventure-ingest"` to `overrides` in `bridge.md`.
