# Setting Canon — Creation (Age of Sorrows)

> Mythic's "world ground-truth" file. For this game the canon is the living **Creation** carried
> by the `exalted3e` skill, so this file is a **pointer + your campaign's local truth**, not a copy.
> Canon overrides invention: consult before inventing. Only narrate a card's **Truth** once its
> in-fiction discovery trigger fires — keep secrets hidden until earned.
